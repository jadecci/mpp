## Multimodal brain-bsed prediction of behaviour

### Reference
Wu, J., Li, J., Jung, K., Eickhoff, S.B., Yeo, B.T.T., Genon, S. (2025). 
Multimodal neuroimaging data boosts the prediction  of multifaceted cognition [Preprint]. 
*Research Square*. doi: [10.21203/rs.3.rs-7721822/v1](https://doi.org/10.21203/rs.3.rs-7721822/v1).

### Usage
Functions in the repository can be installed with:

```bash
git clone git@github.com:jadecci/mpp.git ${project_dir}/mpp
cd ${project_dir} && python3 install ${project_dir}/mpp
```

For description of functions in the feature extraction and prediction pipeline, see `mpp/README.md` 
and `mpp/mfe/README.md` respectively.

For instruction on replication, see `replication/README.md`.

For description of post-prediction analysis scripts, see `replication/analysis/README.md`.
